# CONTRACT: the mpk module

This overlay adds to zistgah/tajziya's CONTRACT.md and to the master contract at
zistgah/governance, and relaxes neither.

© 1993–2026 Abhishek Choudhary. All rights reserved. AyeAI.

**M1. A layer that is not built refuses by name** through `api.refuse`, which names the
engines and packages the registry derives for this node. It never returns a plausible answer.

**M2. A built layer declares what it leaves out** in `scope_excludes`, and cites attested
examples from listed sources.

**M3. No rule, table or word list is written from memory.** Each comes from a listed source.

**M4. Licences.** Only allowed licences enter the folder. Restricted material stays in
`data/local/`, pinned by SHA-256 and ignored by git.

**M5. Every reading is returned.** A ranking may order readings; it never discards one.

**M6. Script, language and standard are separate axes.** Script conversion goes through the
script axis (a Romenagri table where one exists), not through code in this module.

**M7. The module stays inside its folder** (master clause 7): no home, temp or parent paths.

**M8. The module imports `tajziya.api` and nothing else from tajziya.**

Enforced by the generic acceptance test: `bash accept.sh`.
