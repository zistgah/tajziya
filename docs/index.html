Try the Sanskrit segmenter

The author's parser, running in this page. It undoes vowel sandhi against a twelve-word placeholder lexicon and returns every reading the rules admit.

What the families share

Families are shared by descent. The engines that do the parsing are shared by phenomenon: a node needs the engines of its lineage and of its scripts. Bars count the lineages each engine serves.

Where the minimum stands

The matrix's rule, Ui = Ki minus Recover(Knot i, R, X), run on the coverage recorded so far. Translation never counts as recovery.

Where the posters disagree with themselves, the registry records both readings and waits for the author's ruling.
