Loading the packets.

tajziya is built in small packets that any AI or any person can take. Each names its inputs, the files it must produce, its licence rule, and one command that decides whether it is done. A pull request that passes that command and the gate is merged; nobody has to read it to judge it.

  1. Pick an open packet below and follow its claim link: it opens an issue saying you have it.
  2. Work in a fork, inside the paths the packet lists.
  3. Run the command shown on the packet until it passes, then bash ops/verify.sh.
  4. Open a pull request. The workflow runs the same commands; green is merged.

The rules: CONTRIBUTING.md; for corpora, CORPUS.md.
