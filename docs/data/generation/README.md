# How each sutra generates: the sample derivations

© 1993–2026 Abhishek Choudhary. All rights reserved. AyeAI.

Generated by `tools/derivations.py` with vidyut-prakriya 0.4.0 (MIT, github.com/ambuda-org/vidyut) and
its data release 0.4.0. vidyut derives a word from its recipe and logs each sutra it applies; this
folder holds a fixed, deterministic sample of 56,094 recipes, which gives 63,665 derivations:
- every root of the dhātupāṭha in every lakāra, third person singular, active;
- the first 60 roots in every lakāra, person and number;
- the first 200 roots with every kṛt suffix vidyut knows;
- five stems with every taddhita suffix;
- fifteen paradigm stems in every case and number.

597 sutras act in this sample. `<adhyāya>.<pāda>.json` gives, per sutra, the number of sample
derivations it acts in and up to three of the shortest, with every step. `index.json` and `words/`
hold the 10,000-odd derivations the learning page can show step by step. A sutra not in the
sample is not unimplemented: the sample is the first cycle, and widening it is the next.
